# Credits

LAPSLens started as *LAPS for macOS* at The Pennsylvania State University (2018–2021, versions 0.5–2.0). Thank you to Penn State for the start, and to everyone who has helped since.

LAPSLens 3.0 is a ground-up rewrite by Joshua D. Miller, with Claude. The original 2.0 app remains available at tag [`2.0.0(515)`](https://github.com/joshua-d-miller/LAPSLens/tree/2.0.0(515)).

- **Sister project:** [macOSLAPS](https://github.com/joshua-d-miller/macOSLAPS), which also started at Penn State. macOSLAPS writes the password; LAPSLens reads it. The CI's Samba AD domain controller provisioning is shared with macOSLAPS.
